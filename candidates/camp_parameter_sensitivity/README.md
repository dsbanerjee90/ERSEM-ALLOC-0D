# Exploratory ESA-CAMP related parameter sensitivity (candidate, not final)

Includes the original author's +/-10% P1 `alpha` and `sum` pilot sensitivity CSV and archived plotting/analysis scripts from the earlier ten 0D experiments. This is a **candidate** independent of the selected Geider/P-I supplementary figure. The provided original scripts contain older absolute paths and rely on ten `output.nc` files and `allocation_trajectory.csv` files under the original `/work/dba/ERSEM-ALLOC-0D/experiments/`; they are **not** self-contained in this package. Do not describe them as a reproduced experiment or an identifiable parameter inference, and do not assume a `sum` coefficient is the same quantity as the prescribed fC allocation fraction. Review before final release.

ESA CAMP official webpage: https://climate.esa.int/en/observations-and-modelling/camp/
